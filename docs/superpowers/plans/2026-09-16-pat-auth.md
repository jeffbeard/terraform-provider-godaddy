# GoDaddy PAT Authentication Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let the provider authenticate with a GoDaddy Personal Access Token (`Authorization: Bearer <token>`) while keeping the deprecated key/secret pair (`Authorization: sso-key <key>:<secret>`) working.

**Architecture:** A new `api.Credentials` value type validates the supplied credentials and produces the `Authorization` header value once. `api.Client` stores that string and sets it on every request. The provider schema gains an optional `token` attribute; `key` and `secret` become optional, sensitive, deprecated. Token wins when both are present.

**Tech Stack:** Go 1.19 module (toolchain 1.27 locally), terraform-plugin-sdk/v2 v2.6.0, testify assert, `net/http/httptest` for wire-level tests.

**Spec:** `docs/superpowers/specs/2026-09-16-pat-auth-design.md`

**Verification commands used throughout:**

```bash
go build ./...
go test ./...
go vet -tags integration ./api      # compiles integration tests without running them
```

All three pass on `master` before starting.

```go
package api

import (
	"errors"
	"fmt"
	"strings"
)

const errNoCredentials = "no credentials: set token (GODADDY_API_TOKEN) or key and secret (GODADDY_API_KEY, GODADDY_API_SECRET)"

// Credentials holds the values used to authenticate against the GoDaddy API.
// Token is a Personal Access Token and takes precedence when set. Key and
// Secret are the deprecated API key pair and are only used when Token is empty.
type Credentials struct {
	Token  string
	Key    string
	Secret string
}

// Validate returns an error when neither a token nor a complete key/secret
// pair is present. Surrounding whitespace is ignored.
func (c Credentials) Validate() error {
	if c.token() != "" {
		return nil
	}
	if c.key() != "" && c.secret() != "" {
		return nil
	}
	return errors.New(errNoCredentials)
}

// authorization returns the value for the Authorization header. Callers
// must call Validate first.
func (c Credentials) authorization() string {
	if tok := c.token(); tok != "" {
		return fmt.Sprintf("Bearer %s", tok)
	}
	return fmt.Sprintf("sso-key %s:%s", c.key(), c.secret())
}

func (c Credentials) token() string  { return strings.TrimSpace(c.Token) }
func (c Credentials) key() string    { return strings.TrimSpace(c.Key) }
func (c Credentials) secret() string { return strings.TrimSpace(c.Secret) }
```

```go
// last request and replies with an empty JSON array.
func newRecordingServer(t *testing.T) (*httptest.Server, *http.Header) {
	captured := &http.Header{}
	srv := httptest.NewServer(http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		*captured = r.Header.Clone()
		w.Header().Set("Content-Type", "application/json")
		w.WriteHeader(http.StatusOK)
		_, _ = w.Write([]byte(`[]`))
	}))
	t.Cleanup(srv.Close)
	return srv, captured
}
```

```go
// NewClient constructs a new GoDaddy API client or an error if the supplied
// input is invalid. Credentials are validated before the base URL so that a
// missing token or key/secret pair produces the most useful error.
func NewClient(baseURL string, creds Credentials) (*Client, error) {
	if err := creds.Validate(); err != nil {
		return nil, err
	}

	baseURL, err := formatURL(baseURL)
	if err != nil {
		return nil, err
	}

	var netTransport = &http.Transport{
		Dial: (&net.Dialer{
			Timeout: 10 * time.Second,
		}).Dial,
		TLSHandshakeTimeout: 10 * time.Second,
	}

	return &Client{
		baseURL:       baseURL,
		authorization: creds.authorization(),
		client: &http.Client{
			Timeout: time.Second * 30,
			Transport: &rateLimitedTransport{
				delegate: netTransport,
				throttle: time.Now().Add(-(rateLimit)),
			},
		},
	}, nil
}
```

````markdown
The provider authenticates with a GoDaddy [Personal Access Token](https://developer.godaddy.com/en/docs/api-users/auth) (PAT).

### Legacy API key and secret (deprecated)

GoDaddy is sunsetting the two-part API key/secret credential. The provider still accepts it via the
`key` and `secret` attributes or the `GODADDY_API_KEY` and `GODADDY_API_SECRET` environment variables,
and emits a deprecation warning when they are set in configuration. If both a token and a key/secret
pair are present, the token is used. Support for `key` and `secret` will be removed in a future major
version; migrate to a token.

```terraform
provider "godaddy" {
  key    = "abc"
  secret = "123"
}
```
````
